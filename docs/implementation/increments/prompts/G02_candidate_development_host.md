Основание: продолжение подготовки владельцем2026-11-18; [ADR136](../../decisions/ADR-136-candidate-development-host.md), [план](../../groups/G02_FLASH_ADMISSION.md). Предыдущий SDK/build checkpoint завершён; его не повторять.

Реализовать concrete protected config/actual source-runtime-image bindings/fresh fixed official pricing observer, guard перед claim и resource-safe runner/control composition. Применить ECC planner/architect, Python/TDD/contract-first, database review query, independent general/Python/security/silent-failure review; reviewers read-only/blind-first. Детерминированные negative tests и real PostgreSQL для нового account reader, bounded fake HTTPS/Docker для observer behavior; test doubles не выдавать за live evidence. Actual Docker/topology, key setup и весь G156/pre-pr/LinuxCI сохраняются отдельными gates до live.

Отчёт: точные файлы/команды/exits/counts, independent findings и исправления, security/data/API surface, limitations, context и следующий незавершённый preparatory seam. Подготовку целиком готовой не объявлять; G02 ждёт нового явного согласия после её завершения.
