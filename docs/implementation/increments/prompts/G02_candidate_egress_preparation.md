# G156 — candidate egress и проверочный runner: подготовительный scope

Основание: продолжающееся поручение владельца на подготовку, повторное «давай»; [ADR134](../../decisions/ADR-134-candidate-egress-claim.md), [план](../../groups/G02_FLASH_ADMISSION.md). Это не S17/S20/S21 и не разрешение G02.

Реализовать offline/local candidate path после локально TESTED ledger0024: versioned synthetic canonical body codec, backend-owned fixed-account claim/settlement через отдельную private HTTPS app, authenticated LLM_GATEWAY→API, relay only-after-claim и bounded runner/evidence. Caller не получает reserve/create/approve/расширение бюджета по HTTP. Product gateway не включать, fake APPROVED не создавать; ключ/платные вызовы пока отсутствуют. Допуск реальной модели и SLICE01 не обходить.

Файлы распределяются координатором; не менять чужой scope. Shared docs/contracts/composition/relay интегрирует root. Общий runtime только по очереди. Tests: strict payload/unknown version/fields/secret-safe errors; exact final bytes/hash/marker replay; correct/wrong/missing service identity/HTTPS/capability; real PG onceclaim/concurrency/restart/audit outage; real private TLS/CA/hostname checks; actual pinned Bifrost with fake upstream, no live provider. No prompt/response/credential logging; ledger holds unknown billing. Независимые reviewers не авторы проверяемых файлов; security review обязателен. Full pre-pr/Linux CI перед итоговой приёмкой сохраняются, исторические PASS не переносятся.

ECC: architect/security/silent-failure для boundary; Python/contract-first/TDD для codec/control; database reviewer для PG orchestration; test analyzer для stream/cancel/lostresponse/replay; doc updater для context/evidence. Native slash commands/hooks не объявлять запущенными. После реализации дать точные files/API/migration/commands/counts/limitations/review/report и readiness; полную подготовку не объявлять готовой без остальных условий.

Продолжение actual-Bifrost compatibility,2026-11-18: [ADR135](../../decisions/ADR-135-bifrost-candidate-fingerprint-patch.md) разрешает узкую local candidate SDK patch/build/test после воспроизведённой terminal fingerprint loss. Raw tuple проверяется до suppression и после hooks/converters, serializer сохраняет tri-state/zero usage. Exact source/patch/lock/toolchain/binary provenance и separate Go/security review обязательны; original official-image negative/strict adapter/main stack сохраняются. Это не новый framework, не продуктовый deployment или model approval, не старт G02. [Текущий отчёт](../G02_bifrost_candidate_patch_REPORT.md).
