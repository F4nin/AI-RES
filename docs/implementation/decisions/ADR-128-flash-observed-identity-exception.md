# ADR-128 — Ограниченное исключение identity DeepSeek Flash

| Поле | Значение |
|---|---|
| Дата / статус | 2026-11-17 / ACCEPTED владельцем; нормативная часть оформлена, runtime NOT IMPLEMENTED/NOT VERIFIED |
| Ответственный | Владелец (решение и принятие остаточного риска), Implementation Lead (фиксация) |
| Основание | В обсуждении G02 владелец попросил рекомендацию, получил описание вариантов A/B и ограничений; на вопрос о конкретном ограниченном исключении Flash первого среза ответил «да, подтверждаю» |
| Требования / источники | NCP-16, G-156, OD-01/21; DOC-075 §3.3/7.3, DOC-076 §3.1/7, DOC-078 §5.1 (v1.1) |
| Контекст | Технический S16 DONE; доступ к immutable selector не доказан. Rolling alias нельзя выдать за snapshot или заполнить им pinned_model_version |
| Альтернативы | A: сохранить требование immutable snapshot и ждать поддерживаемого механизма; B: ограниченное исключение Flash. Выбран B. Замена провайдера/локальная модель не поручены |
| Решение / обоснование | Ранний полезный первый срез на Flash с явным ограничением воспроизводимости; управляемые версии AI RES immutable, provider identity отдельно наблюдается. При обнаруженном drift результат и последующие вызовы затронутого профиля блокируются до повторной оценки и человеческого approval с аудитом |
| Остаточные риски / owner | Скрытые обновления могут не обнаружиться; нельзя гарантировать вызов прежнего snapshot. Первый изменившийся запрос уже мог быть выполнен и оплачен. Владелец явно принял эти ограничения для указанного scope |
| Не изменяется | Pro CANDIDATE, единичный APPROVED profile, no silent fallback/self-grant, scope данных/egress, budget gates, Bifrost/security acceptance, human approval, независимое QA, Readiness Gate, этапы/очередь SLICE-01 перед S17 |
| Контракты / совместимость | Машинные API/Worker/schema/DB не менялись, baseline contracts не принимался заново. Identity/admission/drift schema и совместимость ещё проектируются до включения; не изобретать поля или fake immutable evidence |
| Scope файлов | Новые canonical075/076/078 v1.1; Registry v4.1 датированная редакция; новый manifest1.3 и путь mirror-map; актуальные prompt/roadmap refs, NCP/status/handoff/gaps/traceability/ECC. Старые normative версии сохранены |
| Проверки реализации перед допуском | Flash-only admission, missing/unexpected identity, no auto-approval первого ответа, drift до принятия результата/stream, последующие/параллельные вызовы и restart, повторное human approval, отсутствие fallback, audit/redaction; прочая DOC-076 §7 матрица |
| Пересмотр | Обнаруженный drift; выход за первый Flash-срез; смена провайдера/второй APPROVED; новые требования воспроизводимости. Автоматического расширения исключения нет |

Подтверждение относится к точной гарантии и scope, а не к запуску платных проверок. Доступ к кабинету/API у владельца есть; ключ может создать в любой момент. Значение не получено и не подключено. Последующим прямым решением владельца лимит технического прогона допуска Flash/Bifrost — 10 USD суммарно, включая повторы и потенциально оплаченные ошибки; это не цель и не бюджет каждого прогона. SLICE-01 в этот лимит автоматически не входит. До выполнения нужны минимальный план с актуальными тарифами и верхней оценкой, безопасный key setup и контроль накопленного/неизвестного расхода. Лимит не увеличивается автоматически.
