# ADR-135 — Локальное исправление SSE fingerprint в candidate Bifrost

**Дата:**2026-11-18. **Статус:** ACCEPTED только технический scope локального PoC; SDK/build/synthetic native compatibility локально TESTED; реальный provider/security acceptance и полный G156 NOT VERIFIED. По просьбе владельца текущий пункт завершён, работа остановлена до новой команды; [финальное evidence](../increments/G02_bifrost_candidate_patch_REPORT.md). Основание: продолжающееся поручение на подготовку, IMPLEMENTATION_CHARTER §1, AGENTS §10, ADR128/131/134; найденный actual-Bifrost blocker из [отчёта](../increments/G02_candidate_egress_preparation_REPORT.md). G02/S17/S20/S21 не начинаются.

## Решение и границы

Исправить библиотечный дефект в отдельной candidate сборке того же Bifrost v2.5.1 на фиксированном source commit `7cb75fb2f8276ca48d0792c857fecb67b8879e2f`. Не менять framework/provider, public AI RES contracts, обязательную metadata, строгий adapter или product factory. Официальный image/S16/main Compose сохраняются. Исходный negative regression официального image остаётся.

Patch ограничена exact DeepSeek Flash native chat streaming path. Handler читает фактический fingerprint **каждого raw upstream frame до suppression/decode/continue** и сохраняет request-local ABSENT/NULL/VALUE. Любая смена присутствия/значения, invalid type/duplicate field/malformed frame даёт безопасный отказ без raw metadata/fallback/retry. В том числе A→B→A на скрытых finish/usage frames. Каждый forwarded/terminal chunk сериализует только собственный реально проверенный факт; terminal использует последнее проверенное наблюдение. Пропуски не заполняются первым fingerprint. Existing WithPreservedUsage/explicit-zero counters сохраняются. Вне exact path legacy поведение не расширяется.

**Уточнение того же parsing boundary после independent security prereview:** вместе с fingerprint сравниваются raw `id` и `model` каждого JSON data frame, включая suppressed finish/usage. Оба — корректно типизированные непустые строки, без duplicate fields; missing/null/wrongtype/change также запрещают success. Сравниваются собственные фактические наблюдения, а не выдуманный expected provider label; до человеческой приёмки реальных значений это не admission. Иначе скрытый model/id A→B→A дошёл бы до adapter уже нормализованным и не мог быть обнаружен. Terminal/forwarded identity берётся из проверенного tuple. DONE/framing не является metadata frame. Request provider/model/native-path selection — из trusted request/context, не из ответа.

**До wire:** converter/posthooks не могут потерять или заменить проверенный opaque fact и изменить id/model/fingerprint. Узкий wrapper только guarded path сохраняет ожидаемый fact до hook и проверяет результат; mismatch/drop даёт sticky отказ и немедленный выход из handler с закрытием upstream. Controlled metadata refusal может передаваться original hook для side effects, но его возвращаемые response/error не превращают отказ в success/skip/fallback. Serializer дополнительно проверяет согласованность base fields и retained fact перед presence overlay. Не расширять general provider utils и не подставлять прежнюю metadata в stripped replacement response. Go tests включают hook/converter mutation/replacement/error rewrite/skip и реальный `sonic.Marshal` transport path.

Ожидаемый узкий source scope: `core/providers/openai/openai.go`, `core/schemas/chatcompletions.go`, `core/schemas/bifrost.go` и отдельные tests/helper при необходимости; при большем затронутом scope сначала пересмотреть этот план. В репозитории AI RES — reviewable patch/tests/build manifest и отдельная Docker build/tooling; полный SDK не vendor-ить. Никаких новых runtime permissions, DB/secret/profile/account seeds или платных вызовов.

## Сборка и provenance

Использовать verified pinned official source snapshot (codeload или Git sparse, как ниже) + SHA256/commit и unchanged upstream go.mod/go.sum; builder/runtime base images закрепить digest до запуска сборки. Manifest связывает source/patch/toolchain/build inputs с immutable local image ID. Официальный transports Dockerfile скачивает published core, поэтому нужен явный local workspace/core replacement и проверка фактического включения patch в binary. Не менять upstream dependency locks молча, не ставить Go глобально. Отдельный task cache tag, без retag main/official image, публикации/release/deployment, registry upload или передачи проектных данных вовне. Установка объявленных pinned build dependencies разрешена §10.

**Конкретизация local candidate packaging:** existing project builder `golang:1.27.4-bookworm@sha256:4fa7c968ba93f1635670522dbb01a2c78150443e1385746924566079f36570ea` (уже pin MinIO build) и official Bifrost runtime `maximhq/bifrost:v2.5.1@sha256:5ec9873acaf1687556b6e4dd854b92b539d9debf87a5a683b66338648b84d3c8`; проверить registry/source pin до запуска. Host Go1.26.3 слишком стар для upstream go1.27.3, auto toolchain download запрещён. Generated go.work явно связывает local core/transports, GOTOOLCHAIN=local и readonly module locks. Существующие compiler/CGO средства builder использовать без apt/apk install; static sqlite/netgo binary проверить на отсутствие ELF interpreter. Upstream `go:embed all:ui` требует assets: для этого inference-only тестового образа выбран фиксированный manifest-hashed headless index stub, без Node/npm и rebuild web UI. Это отдельная candidate packaging, не официальный Bifrost image, не UI acceptance и не продуктовый deployment. License/provenance сохранить; original runtime image не retag-ить. Полнота выбранного source snapshot/checksum/tree validation обязательны до build, частичный download не evidence.

**Уточнение способа получения source:** официальный Git tree содержит около746MiB, преимущественно docs/media, не входящих в build. Вместо загрузки полного codeload допускается bounded temporary partial clone официального репозитория с exact commit и sparse materialization `core/`, `transports/`, `LICENSE` и реально нужных root build metadata. Проверить commit/tree/blob integrity и полноту выбранного subtree, запретить symlink/path escape; затем сделать детерминированный SHA256 snapshot именно этих bytes. Build/provenance фиксируют repository URL, commit/tree IDs, selection, hashes и generated snapshot SHA256; это **не checksum официального full codeload archive**. Lock bytes неизменны. Git metadata/ненужные media/частичные downloads в build context не попадают. Этот вариант заменяет требование full-archive download, не ослабляет exact-source binding и не разрешает сетевые обращения с проектными данными.

## Gates до локального принятия

Go serialization/stream tests: stable VALUE/NULL/ABSENT+explicit-zero usage; legacy records; fingerprint/model/id drift content/finish/usage, suppressed A→B→A; missing/null/duplicate/wrongtype id/model и malformed/invalid fingerprint; safe error/no retry/fallback; upstream closure и request-local isolation. Проверить `go test`/race и `go vet` в зафиксированной среде, доступность staticcheck отметить честно. Independent Go/code/test и отдельное security review — не авторы patch.

После build — отдельные actual patched-image positive SSE и negative drift/cancel/timeout/secret cases через прежний strict adapter, fake provider и internal network/no published ports. Original-image negative и прочие wire cases сохраняются. Это fake-upstream compatibility, не допуск реальной модели. Full preparation pre-pr/Linux CI/live evidence/human acceptance и SLICE-01 остаются. При невозможности безопасной локальной patch SSE gate остаётся закрытым; ослабление обязательного fingerprint запрещено.

## Альтернативы

Ожидание upstream fix оставляет подготовку блокированной. Заполнение terminal первым значением, игнорирование missing fingerprint и passthrough в обход routing facts отклонены. Замена gateway/framework не входит в это решение и требует владельца по прежним правилам.
